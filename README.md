# 👥 HR Analytics Dashboard using Power BI

This repository contains an end-to-end **HR Analytics project** focused on analyzing employee data to uncover workforce trends, attrition patterns, and key HR performance indicators. The project uses **Power BI** to transform raw HR data into meaningful insights that support data-driven HR decision-making.

---

## 🚀 Project Description

The objective of this project is to analyze HR data and identify patterns related to **employee attrition, job roles, experience, salary distribution, performance, and work-life balance**. The dashboard helps HR teams understand employee behavior, reduce attrition, and improve workforce planning.

The project includes data cleaning, modeling, exploratory analysis, and an interactive Power BI dashboard.

---

## ✨ Features

* HR data cleaning and preprocessing
* Interactive Power BI dashboard
* Employee attrition analysis
* Job role and department-wise insights
* Salary and experience distribution
* Work-life balance and performance trends
* Dynamic KPIs, filters, and slicers

---

## 🛠 Technologies Used

* **Power BI** – Interactive dashboard creation
* **Microsoft Excel** – Data cleaning and preprocessing
* **HR Analytics Dataset** – Employee-level HR data

---

## 🧠 Project Walkthrough

1. **Data Loading & Cleaning**

   * Imported HR dataset from Excel
   * Handled missing values and inconsistencies
   * Converted data types and standardized columns

2. **Data Modeling in Power BI**

   * Established relationships between employee attributes
   * Created calculated columns and measures using DAX

3. **Exploratory Data Analysis (EDA)**

   * Analyzed attrition trends
   * Evaluated department-wise and role-wise patterns
   * Studied salary, experience, and age distribution

4. **Dashboard Design**

   * Designed an intuitive and interactive layout
   * Used charts, cards, tables, and slicers

5. **Key Visualization Components**

   * Total Employees & Attrition Rate
   * Department-wise Attrition
   * Job Role Analysis
   * Salary & Experience Distribution
   * Work-Life Balance vs Attrition
   * Performance Rating Insights

---

## 📊 Dashboard Features

* **Employee Overview:** Total employees, active employees, and attrition count
* **Attrition Analysis:** Attrition rate by department, role, age, and gender
* **Salary Insights:** Salary distribution across roles and experience levels
* **Experience Analysis:** Years at company vs attrition trends
* **Work-Life Balance:** Impact of work-life balance on employee retention
* **Interactive Filters:** Department, job role, gender, and education level

---

## 📌 Key Insights

* Certain job roles and departments show higher attrition rates
* Employees with lower job satisfaction and work-life balance are more likely to leave
* Attrition is higher in early years of employment
* Salary and experience play a significant role in employee retention

---
## 🎯 Conclusion

This HR Analytics dashboard provides actionable insights into workforce behavior and employee retention. It can help HR teams improve **talent management strategies**, reduce attrition, and enhance employee satisfaction through data-driven decisions.
